## 🧑‍💻 About Me

I'm a **full-stack developer** who kept asking what happens to a model *after* the notebook cell finishes running — and ended up in **MLOps**. These days I spend my time on both sides of that line: building the product, and building the pipeline that keeps the model behind it alive.

- 🔭 Currently building **end-to-end ML systems** — from the API to the deployment pipeline
- 🌱 Currently learning **Kubernetes, model monitoring and distributed systems design**
- ⚡ I care more about **reproducibility and clean deployments** than squeezing out the last 0.1% accuracy
- 💬 Ask me about **Python, Laravel, React, Docker, or getting a model into production**
- 📫 Reach me at **estiakayon@gmail.com** — always open to collaborating on interesting projects
- 🌍 Based in **Dhaka, Bangladesh**
